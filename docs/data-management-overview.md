# A 数据管理说明

## 本轮功能

- 数据概览：有效论文数、7 / 14 天每日新增、来源分布、摘要完整率和最新 20 篇论文主页。
- 论文导入：从补充论文库选择范围和数量，导入下一批尚未入库的论文。
- 导入记录：查看进度、新增、重复和失败数量，核对批次论文、重试失败任务、导出论文。
- 导入后点击页面顶部的“返回论文导入”继续操作。

## 运行

使用 Python 3.12 和 Node.js 22.18 或以上版本，在仓库根目录执行：

```bash
python -m pip install -r requirements-dev.txt
python -m server.run_local --demo
```

打开终端显示的 `/preview` 地址。首次创建独立演示数据库，并准备 200 篇真实补充论文；补充论文仅在点击导入后进入正式论文库。启动时自动构建前端，关闭启动进程会同时停止它创建的服务。

首次创建演示库时，可通过 `--cvpr-jsonl examples/cvpr_2024_full/cvpr_2024.jsonl` 使用仓库中已有的 CVPR 全量论文。已有演示数据库不会被重新覆盖。演示库中的初始日期按日期分组用于展示，不代表线上定时采集历史。

## 数据交接

在任务详情中“导出论文”，得到当前批次可交接的论文及来源信息。不完整的论文会单独计数。A 新增论文尚未自动进入 B 的知识语料，需与 B 对齐接收步骤；B 的处理结果进入 C 图谱属于后续联调。

## 本轮范围

当前交付基于综合原型 `graph-front`（`d4a62ae`），保留已整合的 B 功能，不包含 `knowledge-enrich` 的新增业务功能。在线采集、文件上传及固定样本导入暂不提供页面入口。底层数据处理与兼容接口保留供现有任务处理和重试使用。

本地数据库、账号配置、缓存、依赖目录和构建产物不属于提交内容。
