# 第一周交付情况与验证边界

这是一份本地开发盘点，不自行宣布团队契约已经冻结。
当前代码已具备“读论文 → 找候选 → 定位证据 → 按需核对 → 保存恢复 → 分状态导出 → 自动检查”的链路。
另有 [Streamlit 本地工作台](../../prototypes/knowledge_builder/README.md)，方便查看和验证效果。

| 第一周方向 | 当前已有 | 尚需实际完成 |
| --- | --- | --- |
| 八类实体、七类关系与证据规范 | 版本化本地模型、机器结构说明和原文定位校验 | 与 C/D 一起冻结正式语义和写入契约 |
| 初始词表与抽取 | 53 个词条，每个新增别名有真实开发参考；20 篇可重跑 | 更广样本覆盖、复杂消歧，不把开发计数当准确率 |
| 确认、驳回、错误纠正 | 核心操作、显示名/证据有限纠正、撤回联动和事件记录 | 身份、类别或方向的复杂纠正仍未实现 |
| 待审与已确认分开保存 | 版本化工作存档、三种状态独立业务文件 | 尚未接入真实图数据库和团队主 API |
| 评估集与标注校准 | 20 篇开发清单、独立测试缺口声明、空白五篇模板和有限评分程序 | 新的未见测试论文、正式封存与少量真人独立标注 |
| 至少五篇演示人工确认 | 五篇原文/预测/证据材料、可实际操作并保存的页面 | 真实阅读和决定仍未执行，自动测试不计入 |
| JSON 交付 | 明确版本、Schema、校验清单、真实样例和测试 | 正式接口认可与跨成员联调 |

这里的核对是开发和质量验证用，不是所有网站用户必须执行，也不要求负责人现在逐条检查全量结果。
真正需要人和团队的工作不由程序伪造；可以先独立验证原型是否符合预期。

## 最省时间的查看方式

```powershell
python -m scripts.knowledge_builder.workbench
```

打开 http://127.0.0.1:8501 ，先看概览，再选一篇论文看原文和证据。
只看自动结果不会创建确认决定；决定保存后退出并重开可以恢复。
不使用页面也可继续运行 preview、prepare_validation、export 等原命令。
