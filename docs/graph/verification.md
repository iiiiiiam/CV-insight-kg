## 查询测量

样本只有 5 篇，预热后各执行 10 次，测量 Python Repository 调用的完整耗时：组合检索中位数 15.07 ms / 最大 35.92 ms；详情 16.61 / 27.84 ms；2 跳 19.16 / 48.45 ms。原始汇总在 query-measurements.json。**这不是生产数据规模、并发压力或端到端渲染性能证明**；后续需用全量数据补测计划中的 2 秒指标。
