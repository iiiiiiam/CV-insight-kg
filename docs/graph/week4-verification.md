## 异常与性能检查

* 非 effective 格式、错误 revision、错误计数：API 422，活动空快照仍可读取。
* 错误 expected-active/旧事件：CAS 409，指针不变；旧内容不能携带过期 CAS 覆盖当前范围。
* 同 revision 重导入：replay=true；相同当前版本再发布：unchanged=true，代数不增加。
* 活动版本 A→B→A 后，原来 A 的旧代数请求：拒绝，防止仅按 ID 比较遗漏此变化。
* 导入写节点后异常：真实 Neo4j 事务回滚，目标批次及节点均未残留；恢复后合法输入可重试成功。
* 发布已经写指针但提交前异常：真实事务回滚，活动 ID/代数和旧可读数据保留；恢复后可发布。
* 完整性检查失败：保留旧版本；原测试还覆盖计数/证据不一致、并发导入和并发发布。
* 数据库连接不可用：接口边界注入 ServiceUnavailable 验证503、失败阶段与未知提交结果标志；另以真实引擎事务内异常验证回滚。未停用真实生产连接做网络故障测试。
* 一个测试专用大作者论文：256位共同作者，响应只取5项，每对只取1篇，total准确；整个导入/发布/查询测试0.480秒。此为明确标记的 fixture 压力测试，不是 A/B 业务数据，也不是生产性能承诺。
* 同名不同 ID、机构仅在另一篇有证据、空筛选、末页、共享论文截断、重复点击同请求的后端返回一致性通过。
