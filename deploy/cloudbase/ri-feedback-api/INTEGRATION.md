## 用户操作和界面分工

| 入口 | 用途 |
| --- | --- |
| 知识证据与个人调整 | 查看依据、个人改名/隐藏、主动提交公共反馈；个人调整不上报 |
| 我的反馈 | 同卡显示说明、送达状态、团队回复；手动刷新回复或重试原记录 |
| 知识管理 → 用户反馈 | 合并本机和云端同一反馈，在同一面板核对、修正并回复；再次点击同条收起 |
| 知识管理 → 论文批次 | 原论文批次操作 |
| 顶部用户名或左下角身份 → 账号与安全 | 复用原 `/account` 页面，改自己的密码；owner 还可管理团队账号 |

管理员只保留一个“刷新反馈列表”按钮：团队会话有效时获取云端最近记录并合并，否则刷新本机记录。打开页面和读取已有回执不访问云端；登录、提交、手动获取反馈、保存回复及查回复按操作联网，无后台轮询。

普通用户无需填写云密钥或运行脚本。软件内置公开服务地址，先保存本机反馈，再尝试发送一次。网络失败保留原记录，手动重试复用原编号和查询凭证。云端未收到不能显示已送达。

详情取消固定高度与嵌套滚动，反馈入口放在长原文之前；完整原文上下文按需展开。状态刷新逐条处理；已撤回且当前后台不存在的旧回执显示历史存档，不影响新记录。

## 处理规则与失败恢复

- 原改名、排除、补词、撤回等知识规则保留。对应论文/版本不匹配时只能说明保留并回复，不能直接修正知识。
- 知识处理和待发送回复在同一本机事务中记录。云端发送失败显示“回复待发送”，重试仅发送回复，不重复修改知识；版本冲突提示核对，不自动覆盖其他管理员结果。
- 本机有完整知识处理记录时可依原并发及依赖检查撤回，并把反馈重新打开；仅有云回复的旧记录没有知识前后记录，不提供“撤回知识处理”。
- 云端已处理、本机仍 open 的历史兼容：提交只使用当前提交者拥有的本地云回执缓存，把明确结束的记录排除出本次去重候选。仍待处理的同条反馈继续去重；不增加云查询，不伪造本机知识处理。
- 云回复不等于公共知识修改。知识发布沿用原 B → D → C 流程，尚未提供所有安装端的自动知识同步。

## 账号权限与存档

团队账号存入云数据库，逐条新增/更新，带版本检查，不再替换整份账号 JSON。

- `owner`：管理其他团队账号（新增、停用、改权限、重置密码），以及处理反馈。
- `admin`：处理反馈、改自己的密码，不可管理其他账号。
- 改自己的密码须验证当前密码；改密后重新登录。不能自行停用或降级自己，数据库保护最后一位启用的 owner。
- 云会话当前有效期 **1 小时**，保存在本机后端会话中，不返回浏览器。每次云管理请求检查账号启用状态和版本，停用或修改后旧云会话失效。用户提出的 24 小时会话尚未实施。
- 原本地管理员登录保留；本地管理员身份不自动授予团队云权限。团队登录使用原管理员登录页，普通用户注册不产生团队管理员。

回执 SQLite 文件为 `cloud-feedback.db`，默认位于 `D_USER_STORE` 同级；无指定时使用 B reviews 或 `server/.local`。单条查询凭证由稳定的会话密钥、安装编号和本地编号派生，不发到前端。迁移须保留数据和原 `SESSION_SECRET`，更换云环境应使用独立回执库。浏览器回执与个人调整留在对应浏览器，不提供跨设备找回。

## 已知边界

最近 20 条无分页；文字说明最多 1000 字、payload 2048 字节，超出保留本地并提示，不截断。当前速率限制仅函数实例内生效（提交 10 次/分钟、公开查询窗口 30 次/分钟、团队登录 12 次/分钟），不是全局额度硬上限。正式开放前仍需评估网关防滥用、监控、容量和真实并发。当前没有云端撤回、完整云操作历史和跨设备回执恢复；本地撤回不会自动删除团队副本。


登录兼容补充：本机云登录客户端等待 12 秒，浏览器管理员登录等待 20 秒；服务故障提示 503，限流为 429，仅凭据错误为 401。网络故障不记为输错密码，不自动重试。CF-10 说明及检查结果见 BUGFIXES.md。

账号并发保护：账号写事务通过守卫行锁串行化，事务内重查操作者有效性与版本，并保护最后一位启用的 owner。不要使用真实互相停用来做日常验证；真实数据库并发仍未验收，回归复用说明见 BUGFIXES.md。
