# A · 论文数据管理

使用 Python 3.12 和 Node.js 22.18 或以上版本，在仓库目录安装依赖，然后启动：

```bash
python -m pip install -r requirements-dev.txt
python -m server.run_local --demo
```

启动时构建界面并运行 A、任务处理和网页服务。浏览器打开终端给出的 `/preview` 地址。首次创建独立演示库，准备 420 篇已入库论文和 2,534 篇可手动导入论文；已有数据和配置保留。关闭终端中的启动进程会同时停止它创建的子进程。

- 数据概览：去重论文、每日新增、来源、摘要完整率和最新 20 篇论文主页。
- 论文导入：从补充论文库选择范围和数量，导入下一批新论文。
- 导入记录：来源与会议筛选、进度、批次对比、新增/重复/过滤/失败、论文核对、失败重试和数据导出。
- 交接后台：发送正式或手动导入批次给 B，支持撤回交接、回执、进度和失败重试。
- 报告后台：冻结数据、生成论文/来源/质量章节及 ZIP，支持 B/C 数据、进度、重试和下载。

验证：

```bash
python -m unittest discover -s tests -p 'test_reserve.py' -v
```
