# A · 论文数据管理

提供论文导入、清洗去重、来源追溯、批次对比与撤回，以及数据管理概览。

## 启动

使用 Python 3.12、Node.js 22.18 或以上版本，在仓库根目录执行：

```bash
python -m pip install -r requirements-dev.txt
python -m server.run_local --demo
```

打开终端显示的 `/preview` 地址。首次启动会从仓库现有论文文件初始化 **420 篇已入库论文**和 **2,534 篇可手动导入论文**；后续启动保留操作结果。

## 使用

- 数据概览：论文数量、来源、摘要完整率、7 / 14 天新增与撤回，以及最新 20 篇论文主页。
- 论文导入：选择会议和数量，点击“导入下一批”，查看真实入库进度。
- 批次管理：对比批次、搜索论文、处理失败、导出及选择批次撤回。
- 来源与质量：来源配置、字段缺失筛选和报告下载。

批次展示编号使用 M（手动）和 A（自动）。演示历史使用真实论文，初始日期与自动采集方式为模拟展示；新导入会真实写入数据库。
